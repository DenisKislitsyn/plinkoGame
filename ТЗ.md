## **Техническое задание: Реализация игры "Плинко"**

### **Задача:**

Реализовать игру "Плинко", в которой игрок опускает металлические шарики в лабиринт из кеглей с целью попадания в корзины внизу.

Пример из игры “Отель мечты”(только пример, не обязательно делать один в один)

### **Реализация:**

1. **Классическая механика "Плинко":**  
   * Лабиринт из кеглей с несколькими корзинами внизу.  
   * Реализация физики падения шариков через кегли.  
2. **Регулировка вероятности:** Возможность задать вероятности попадания в каждую корзину вручную , через конфигурационный файл.  
3. **Очки:** Начисление очков в зависимости от корзины, в которую попал шарик.  
4. Количество корзин \- 10  
5. У игрока есть ограниченное количество шаров.  
6. Один шар восстанавливается за N секунд  
7. Шары могут восстановиться только до определенного в параметрах значения(кнопкой для тестирования можно начислить больше)

### **Параметры игры:**

1. **Стартовое количество шаров:** Изначальное количество шариков в инвентаре.  
2. **Время на восстановление 1 шара:** Время, через которое один шарик добавляется в инвентарь.  
3. **Вероятности для попадания шара в корзину:** Возможность ручной настройки вероятности попадания шара в каждую корзину.  
4. **Количество очков для каждой корзины:** Очки, присуждаемые за попадание шара в конкретную корзину.  
5. Максимальное количество восстанавливаемых за время шаров

### **Интерфейс:**

1. **Кнопка для падения 1 шара:** При нажатии запускает один шарик.  
2. **Кнопка для падения нескольких шаров:** Возможность запускать несколько шариков одновременно.  
3. **Кнопка для начисления шаров (для тестирования):** Увеличивает количество шариков в инвентаре вручную.  
4. **Текст с количеством шаров в инвентаре:** Отображение текущего количества шариков.  
5. **Текст с таймером восстановления:** Отображение времени до восстановления следующего шарика.

### **Отладка:**

**Вывод статистики попаданий в корзины:**

* Количество шариков, попавших в каждую корзину.  
* Общие очки игрока.  
* Процентное соотношение попаданий в каждую корзину.

Вывод через render:draw\_text
